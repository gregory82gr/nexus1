MISSION READINESS

Reshaped around the real domain: no capability/dose data exists to evaluate abstract mission types live against the fleet, so this screen shows the unit's real, already-dispatched missions below, and — separately — the real, recorded readiness assessment for a specific mission you look up by id. The mission list carries each mission's code but not its numeric id, so the lookup is a manual tool, not a click-through from the list.
