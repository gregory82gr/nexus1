The book's own source computes grid frequency from local turbine RPM — physically backwards, since a synchronized grid has one shared frequency every connected turbine tracks, not one any single turbine sets. The fix here is structural, not a different formula: turbine shaft speed stays a real, separately-sourced measurement; grid frequency, phase angle, breaker state, and sync status are a distinct, unconnected field set below it. Active power, reactive power, generator voltage, and power factor were checked directly in Instrumentation and found to have never been seeded or measured anywhere in this system — an honest gap, not shown as if real.
