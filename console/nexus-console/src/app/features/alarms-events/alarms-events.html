ALARMS & EVENTS

No decorative alarm generation here — the book's own source draws 11 pooled events at random every 5 seconds; none of that is ported. Every alarm below comes from the real fleet-wide endpoint. This system has one real threshold-check mechanism (AlarmDefinition.Evaluate) but nothing invokes it automatically yet, so these alarms are demo/test residue, not proof of live condition monitoring. Control Rods stay read-only everywhere in this console — there is no SCRAM write path anywhere, so the book's own "alarm fires before the effect happens" risk does not apply here. Acknowledge below is a real write: it changes the alarm's own state, nothing more.
