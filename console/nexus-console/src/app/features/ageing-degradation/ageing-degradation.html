No life-consumed percentages or progress bars here, by design: a filled bar asserts continuous measurement toward a known, monotonic endpoint, which almost nothing on a decade timescale (vessel embrittlement, tube wear, insulation ageing) actually has. Each case below shows its real mechanism, severity, when it was detected, and how many measured trend points exist — a count of data points, not a fabricated percentage. Fleet-wide, not scoped to one unit — the real query behind this has no unit parameter at all. No per-point chart is shown: the endpoint returns a trend-point count, not the individual measured values or a limit to chart them against.
