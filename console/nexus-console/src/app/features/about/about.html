About NEXUS-1

STATIC REFERENCE — NO BACKEND CALL

This console is a demonstration/portfolio Angular port, built chapter by chapter against a real, intentionally partial .NET 8 backend — not a production plant-control system, and not the book's own fictional Volume III. Every screen either shows a real value traced back to real backend code, or names the gap explicitly when the underlying data or mechanism doesn't exist yet.

Real stack

  • Frontend — Angular 18, TypeScript 5.5, RxJS 7.8, Three.js (Plant 3D View).
  • Testing — Jest for unit/component tests (mocked HTTP); Playwright for real, unmocked end-to-end sessions against a live backend.
  • Backend — .NET 8, one bounded context per real domain area, composed selectively behind a BFF.

The honest-gap discipline

This is this console's actual recurring behavior, not a claim made once here: every chapter of this build investigated the real backend directly before writing a screen, and where nothing real backs a value, the screen says so — a "NO SOURCE" pill, a specific refusal message, a fleet-wide label where per-unit data doesn't exist — rather than filling the gap in with something that merely looks plausible.

Scope

Advisory and illustrative only. Nothing in this console issues a command to any real plant equipment, and no screen should be read as an operational safety system.
